# 文笔复刻1.0 · 已知局限与适用边界

> 本文件记录经实测验证的边界，任何使用前请先确认是否落在适用范围内。逐条来自
> SPI/AoT/WFP 三模块的冻结基线、回测报告与校准实验（2026-10-11/12）。

## 一、精度边界（画像级）

| # | 局限 | 实测依据 | 处置 |
|---|---|---|---|
| 1 | **SPI 零样本人格分数精度有限（r≈0.29）**，与 LLM 人格测量文献一致 | SPI 尺子 v1.0 基线 | 只作人设底色与倾向提示，**不作判据**；生成校验不依赖分数绝对值 |
| 2 | **AoT 思维画像为冻结尺子 v1.0（25 维）**，效标反标定已跑（6,006/6,006，收敛 0.52–0.88） | AoT v2.0 报告 | 维度分用于相对排序（top5），单维绝对值谨慎解读 |
| 3 | **两把尺子（SPI/AoT）都不含文风 L1–L3**：不测句法、词汇、篇章 | 方案定稿 | 文风主体靠 WFP；叙事套路靠**原文 few-shot + 体裁分析**补足 |

## 二、判别边界（回测什么时候会失效）

| # | 局限 | 实测依据 | 处置 |
|---|---|---|---|
| 4 | **异质作者 + 短块语料时 Delta 判别失效**：块 <300 字占比高 → 基线 sd 过大 → z 稀释 → 判别比≈1× | WFP v0.4.12/13 跨作者验证（异质语料 1.03×→1.06×→1.70×） | 语料块尽量 ≥500 字；异质语料用**分层基线**（按块长分层）或非参数判据；同质长文基线不受影响（实测判别比可达 4×+） |
| 5 | **生成文过短（<800 字）时判别力弱**：短文本特征方差大 | 分层实验：≥800 字 29 块恢复 1.70× | 生成文建议 ≥800 字再回测 |
| 6 | **L3 软评分器单篇噪声 ±1–2 分**（vs 422 篇聚合基线），过修/欠冲判断部分来自度量噪声 | v0.4.15 校准实验 | 涉及 L3 兑现判断时**多篇合评降噪**，勿凭单篇 17 维分数下结论 |

## 四、运行条件

| # | 条件 | 说明 |
|---|---|---|
| 9 | **API key**：SPI/AoT/WFP-L3 打分均需 DeepSeek key（`.env` 中 `DEEPSEEK_API_KEY`） | **无 key 自动进入模拟模式**，产物带 `simulated: true`，仅可用于流程验证，**不可当真值** |
| 10 | **SPI 需安装**：`uv pip install -e <SPI_ROOT>`（提供 `spi-quant` CLI） | 未安装时 SPI 画像不可用，人设卡降级为 AoT+WFP 或仅 WFP |
| 11 | **语料要求**：必须是对象本人真实文本；建议 ≥20 篇且单篇 ≥300 字 | 样本不足时基线 sd 大、判别弱；先用 WFP 硬指标 + 原文 few-shot 兜底 |
| 12 | **尺子冻结规则**：任何因子链/维度/模型/评分协议的变更 = 新版本，必须重跑基线验证并记录 | 见 SPI/AoT/WFP 各自 README 的变更规则 |

## 五、生成端经验（校准结论，非硬保证）

- **统计层数值约束直接有效**：把 WFP 硬指标目标值写进 prompt 后，模仿文 Delta 连续收敛
  1.445 → 1.355 → 1.263（多轮回测 v3/v4/v5）；但逼近真实文基线（约 1.49）后存在天花板。
- **软特征需 few-shot/校准通道**：单纯"顶格对齐"prompt 会导致 L3 过冲（评价/说理/修辞）；
  用负向锚 + 中低位目标值 + 自然出现描述（v5 做法）可恢复视角/情绪/修辞。
- **低分维度要设锚**：目标值低的维度（引语/论证）若不写"少用"，生成端默认会多用。
- 生成文应先自测硬指标（句长/问句/语气词/隐喻/我:你），命中后再看 L3 兑现。
